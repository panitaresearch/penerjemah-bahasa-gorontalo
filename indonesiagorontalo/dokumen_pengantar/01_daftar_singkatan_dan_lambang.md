## II. Lambang

| Lambang | Fungsi dan Penjelasan |
| :---: | :--- |
| `[ ]` | kurung siku, pengapit unsur fonetis |
| `/ /` | pasangan garis miring, pengapit unsur fonologi |
| `-` | garis datar kecil digunakan sebagai penanda morfem terikat |
| `⇒` | panah, lihat |
| `( )` | kurung biasa, digunakan untuk: (i) penanda unsur opsional, (ii) glos, (iii) perincian makna, (iv) padanan, atau |
| `-/-` | garis miring di antara dua garis hubung, lambang pemisah konfiks |
| `∅` | zero, nol bergaris, penanda morfem zero |
| `~` | garis bergelombang, penanda alomorf |
| `1, 2, 3 dst` | penanda perincian makna (angka ini ditempatkan di antara lambang `( )`) |
| `I dst` | angka Romawi digunakan sebagai penanda kelas kata / homonim |
| `= =` | urutan garis datar berlapis, penanda rujuk silang / pengganti lema bahasa Indonesia dalam contoh kalimat |
| `_____` *(atau cetak miring)* | garis datar panjang di bawah (atau teks cetak miring), penanda contoh kalimat BG (Bahasa Gorontalo) |
